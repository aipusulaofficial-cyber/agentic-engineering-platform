# SLO / SLI

The reference runtime now emits latency and execution-status signals, but it does not claim production SLO targets.

Required SLIs once deployed: p50/p95/p99 latency, throughput, error rate, concurrency/saturation, dependency health, resource usage and domain-specific correctness/regression metrics.

Targets must be calibrated from measured workloads before being declared contractual.
